# Улучшения системы постинга Bali

## Дата: 2026-01-22

### ✅ Выполненные улучшения

#### 1. **Автоматическая обработка ошибок в `poster.py`**

Улучшена логика обработки ошибок при постинге:

- **Блокирующие ошибки** - теперь автоматически переводят группу в статус `inaccessible`:
  - `"The channel specified is private"` - канал приватный
  - `"you lack permission to access it"` - нет разрешения на доступ
  - `"you were banned from it"` - забанен в канале
  - `"allow_payment_required"` - требуется оплата
  - `"chat_send_plain_forbidden"` - текстовые сообщения запрещены
  - `"topic_closed"` - топики закрыты

- **Умная проверка групп без доступных аккаунтов**:
  - Если все аккаунты забанены в группе, система проверяет последние ошибки
  - Если все ошибки блокирующие (≥3 ошибки с ключевыми словами), группа автоматически переводится в статус `inaccessible`
  - Иначе группа переводится в статус `no_accounts_left`

#### 2. **Новый скрипт проверки статусов**

Создан скрипт `scripts/check_accounts_status.sh` для детальной проверки:

- Статусы всех аккаунтов
- Количество забаненных групп по каждому аккаунту
- Статистика успешности постов за 7 дней
- Группы без доступных аккаунтов
- Группы с частыми ошибками

#### 3. **Улучшен `daily_check.sh`**

Добавлены новые секции:

- Процент успешности постов за сегодня
- Количество неуспешных постов
- Список проблемных групп (≥3 ошибки за сегодня)
